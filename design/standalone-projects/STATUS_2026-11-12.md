## Hospedagem

Os três frontends React têm publicação estática por GitHub Pages, verificada via HTTP 200 e navegação em Chromium. Os três também possuem vercel.json, possibilitando importação posterior no Vercel.

A Vercel está conectada à conversa, mas o terminal do Arch não recebeu essa sessão autenticada. Uma implantação temporária de teste retornou HTTP 403 para visitantes externos e NÃO foi anunciada como aplicação online.

A API de viagens usa Prisma e SQLite no disco. Serveless com armazenamento temporário não preserva os registros; implantar rotas de escrita exige banco persistente, validação de permissões e estratégia de autenticação. O Java Order Management é CLI e não requer servidor.

Os runners de qualidade do GitHub Actions seguem bloqueados por cobrança. Os resultados de testes locais não devem ser anunciados como CI remoto aprovado.

## Continuidade

O site principal BLACKSITE agora exibe botões para as três demos React, além de links para código e documentação. Antes de aprimorar os demais repositórios, escolher qual vaga e qual problema será atendido; não inventar sistemas para preencher a vitrine. Cada repositório mantém seu histórico, sua autoria original e documento técnico de escopo.
